C++ IT Ticketing System
This is a personal C++ programming project designed to simulate an IT help desk ticket management system.
Purpose is to brush up my programming skills on apply data structures and algorithms, and database theory. 


Planned Features
-User login system
- Create and describe IT support tickets
- Categorize   requests
- Save tickets to text files
- View and update existing tickets
- Menu-driven user interface
